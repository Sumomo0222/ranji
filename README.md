# 燃记 · 个人健身与饮食管理

纯静态的移动端网页应用：记录每日饮食与运动，拍食物照片在**本机**估算热量与营养，上传运动截图自动读出时长和消耗，自动生成每周健身报告。没有服务器，所有数据只保存在你设备的浏览器里。

在线地址：<https://sumomo0222.github.io/ranji/>

## 功能

- **今日看板**：打卡进度（早 / 午 / 晚 / 运动 / 打卡）、热量摄入与运动消耗、营养分布、健身目标进度、当日记录
- **记饮食**：拍照估算（本地 MobileCLIP 识别，给出 5 个候选）、食物库（168 种）、手动填写；份量可调，热量与营养素可手动修正
- **记运动**：上传截图识别（本地 OCR，支持中英文 App）、手动记录（按 MET 与体重估算）；消耗可修正
- **打卡提醒**：可设多条提醒（时间 + 星期）；应用打开时到点提醒，并可一键同步到系统日历
- **趋势**：近 7 / 14 / 30 天的热量收支、营养结构、体重曲线、打卡日历
- **周报**：按周自动生成，含亮点与下周建议，可复制文字或导出长图
- **数据**：导出 / 导入备份（含照片）、离线缓存、可添加到主屏幕当 App 用

## 本地运行

```bash
npm ci                      # 安装依赖（需要 Node 20+）
npm run engines             # 下载识别引擎文件到 static/（约 45 MB，不进 git）
npm run build               # 构建到 docs/
npx serve docs              # 或任意静态服务器；站点挂在子路径下也能正常工作
npm test                    # 单元测试
npm run e2e                 # 端到端测试（需要本机装有 Google Chrome）
```

首次打开可以用 `?demo=1` 载入示例数据，先看看看板、趋势和周报。

## 目录

```
src/
  main.js            入口：标签页路由、主题、提醒调度、Service Worker 注册
  core/              日期、热量与营养计算、周报生成、存储、提醒、截图版面解析（纯函数，有单元测试）
  engine/            食物照片识别、截图 OCR 的接入层（按需加载）
  views/             首页、趋势、周报、我的、各记录流程、首次引导
  ui/                样式系统、图表、底部面板等界面组件
  data/              食物营养成分表、运动类型与 MET
static/              字体、图标、纹理，以及识别引擎文件（tools/fetch-engines.mjs 生成）
tools/               构建、部署、测试脚本；识别引擎的评测工具与记录见 tools/ENGINES.md
docs/                构建产物（部署内容，不进 git）
```

## 数据与隐私

- 饮食、运动、打卡、体重记录保存在浏览器 `localStorage`，照片与截图保存在 `IndexedDB`
- 食物识别与截图文字识别都在浏览器本机完成，照片和截图不会上传
- 换设备或清理浏览器数据会丢失记录，请用「我的 → 数据 → 导出备份」

## 已知限制

- 网页无法在后台定时推送：关掉浏览器后，提醒依赖「同步到系统日历」；iPhone / iPad 上发系统通知需要先「添加到主屏幕」
- 热量、营养和运动消耗都是估算值，食物识别对相近菜式只能给出候选，请按实际情况修正
- 首次使用拍照识别需要下载约 26 MB 模型，截图识别约 6 MB，之后可离线使用
