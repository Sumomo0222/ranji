# 识别引擎说明与评测记录

燃记的两个「智能」功能都在浏览器本机完成，照片与截图不会上传：

| 功能 | 模型 / 组件 | 站点里的文件 | 下载量（估算） |
| --- | --- | --- | --- |
| 食物照片识别 | MobileCLIP-S0（图像编码器，fp16）+ ONNX Runtime Web 1.31.1（wasm 后端） | `static/models/mobileclip/*`、`static/vendor/ort/*` | 约 26 MB |
| 运动截图识别 | Tesseract.js 7.0.0，`chi_sim` + `eng` 语言包 | `static/vendor/ocr/*` | 约 6 MB |

两者都是首次使用时才下载，之后由 Service Worker 缓存，可离线使用。

## 食物照片识别

流程：照片 → 短边缩到 256、居中裁剪 → 图像向量 → 与 168 种食物、17 条非食物对照词的预计算文本向量算余弦 → 取最像的 5 种。

- **模型来源**：`Xenova/mobileclip_s0`（Apple MobileCLIP 的 ONNX 转换，修订 `757d59c`），许可为 Apple 的 MIT 式许可，见 `static/models/mobileclip/LICENSE.txt`。
- **不能用仓库里的 int8 版本**：`vision_model_quantized.onnx` 在浏览器与 Node 里都输出错误结果（猫的照片 97.6% 判成「鸟」，与 fp32 结果的余弦相似度仅 0.016）。fp16 版（21.8 MB）与 fp32 版（43.4 MB）的输出在 38 张测试图上余弦值到小数点后三位一致，因此站点用 fp16。
- **预处理一致性**：浏览器 canvas 的缩放裁剪与参考实现（Transformers.js 处理器）相比，图像向量余弦 0.984–0.998，首位预测完全一致、概率几乎相同。
- **运行环境**：无跨域隔离头、挂在子路径下的纯静态站点，wasm 单线程；无头 Chrome 单张推理约 170–220 ms。

评测（38 张图，33 张食物 + 5 张非食物；图片来自图库搜索，仅本地测试，不随站点分发）：

| 指标 | 结果 |
| --- | --- |
| 首位命中 | 29 / 33 |
| 前三命中 | 33 / 33 |
| 食物图的最佳食物相似度 | 0.24 – 0.36 |
| 非食物图的最佳食物相似度 | 0.08 – 0.17 |
| 非食物图的最佳对照词相似度 | 0.20 – 0.28 |

4 个未首位命中的都是相近菜式：鸳鸯火锅 → 一桌家常菜、蒸笼里的饺子 → 小笼包、两碗拉面 → 汤面、巧克力蛋糕 → 布朗尼。

据此设定的阈值（写在 `text_embeds.json`）：最佳食物相似度低于 0.20，或低于最佳非食物对照词时，判为「没认出食物」而不是硬猜。

## 运动截图识别

一张截图跑两到三遍 OCR，再把各遍的文字按位置合并，交给版面解析器：

1. 原图缩放到 585 px 宽识别一遍，并据此判断画面明暗；
2. 深色截图再做两遍「反相 + 3×3 最小值滤波加粗笔画」，宽度分别为 585 与 468 px；浅色截图只再跑一遍 468 px。

解析器（`src/core/screenshot-parse.js`）不按行做正则，而是按版面几何：每个数字去看同一行左侧的标签、右侧的单位、以及最近的上方/下方说明，再叠加格式规则；配速、心率、步频、速度、时钟与日期会被排除。

评测样本是 9 张用 HTML 渲染的仿真截图（Apple 健身、Keep、Strava、华为运动健康、微信运动、健身房、动感单车、游泳、Garmin 风格，中英文、深浅色都有），由 `tools/ocr/make-samples.mjs` 生成：

| 配置 | 字段正确数（共 33） |
| --- | --- |
| 只按行匹配正则（早期方案） | 12 – 15 |
| 版面解析 + 单遍（原图 0.5×） | 27 |
| 版面解析 + 两遍（原图 0.5×、反相 0.5×） | 31 |
| 版面解析 + 两遍，只用中文包 | 24 |
| 版面解析 + 两遍，只用英文包 | 22 |
| **版面解析 + 三遍（最终方案）** | **32** |

剩下 1 个未命中是一张图里 60 px 粗体的距离「5.21」被读成 `D.21`。无头 Chrome 下每遍识别 150–600 ms。

## 复现

```bash
# 食物识别：预计算文本向量、打包站点文件、浏览器内评测
node tools/clip/embed-text.mjs      # 需要 tools/clip 的依赖与 tools/clip/cache/hf 下的模型文件
node tools/clip/build-embeds.mjs
node tools/clip/browser-eval.mjs fp16=static/models/mobileclip/vision_model_fp16.onnx

# 截图识别：生成仿真截图并评测
node tools/ocr/make-samples.mjs
node tools/ocr/run-harness.mjs --passes=orig:0.5,inv:0.5,inv:0.4
```
